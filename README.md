# Md Rashedul Hasan — Stunning 3D CV

A cinematic interactive CV built with HTML, CSS and JavaScript. No framework or paid assets required.

## Run
Open `index.html` in a browser.

## GitHub Pages
Create a GitHub repository, upload the files, then enable GitHub Pages under Settings → Pages → Deploy from branch → main → /(root).


## Profile photo
`profile.jpg` is the profile image used in the academic CV. Keep it in the same folder as `index.html` when uploading to GitHub.


## Design direction
Professional academic portfolio with a dark research-lab aesthetic. Reactive cursor, 3D card tilt, magnetic buttons, orbital hero, research section, and subtle motion are intentional presentation effects.
